# Sinusoidal Hull-White Interest Rate Model

This project implements an extension of the one-factor Hull-White model by introducing a sinusoidal time-varying mean reversion parameter to capture long-term cyclical behavior in U.S. Treasury yields.

## Motivation

Empirical evidence suggests that long-term interest rates exhibit persistent cyclical patterns.  
The standard Hull-White model assumes constant mean reversion, limiting its ability to capture such dynamics.

This project introduces a smooth periodic structure in the mean-reversion speed.
